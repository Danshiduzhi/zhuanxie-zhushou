# 转写助手 v2.0

把视频 / 录音转成文字与 Word 文档的桌面软件（Windows），另附手机端网页版。

- **电脑版**：本地离线识别（faster-whisper），输出 `文字记录.docx` + `总结提炼.docx` + `音频.mp3` + `.srt`，一键安装
- **手机版**：录音或选文件，直接调用你自己配置的语音识别 API，即时出文字（iOS / Android 通用）

## 安装（Windows）

下载 `转写助手_Setup_2.0.exe`，双击安装。默认装到当前用户目录，**不需要管理员权限**。

- 勾选「离线识别模型」安装包约 3.5 GB，装完断网可用
- 不勾选则程序较小，首次转写时自动联网下载模型

用户数据（视频、音频、文档、配置、日志）单独放在：

```
%LOCALAPPDATA%\转写助手\
├ 01_视频    02_音频    03_转写    04_文档
├ config.json      ← 设置（API Key 用 Windows DPAPI 加密）
├ logs\app.log     ← 运行日志（界面右上角可查看）
└ data\tasks.json  ← 任务记录
```

卸载程序不会删除这个目录，数据可保留。

## 功能

| 功能 | 说明 |
|---|---|
| 本地识别 | 内置 large-v3，GPU/CPU 自动选档，完全离线 |
| 热词表 | 人名、术语，显著降低专名错字 |
| 智能校对 | 可选，修正同音错字、补标点、统一术语（需 API Key） |
| 生成总结 | 可选，摘要 / 要点 / 详解 / 行动项 |
| 存疑标注 | 置信度低处标 `[存疑]`，文末汇总，点击可试听 |
| 保留源文件 | 可关，关掉后转写完成即删除源视频与音频，只留文档 |
| 断点续跑 | 识别结果落盘复用，重跑不重复计算 |
| 批量队列 | 拖拽多个文件，串行处理，实时进度，可取消 |

## 开发

```bash
python app.py                 # 开发模式启动（原生窗口）
python app.py --no-window     # 只起服务 http://127.0.0.1:8765
python app.py --portable      # 绿色模式：数据跟随程序目录
python pipeline.py all        # 命令行批量处理 01_视频/
```

## 打包

```bash
tools\build_installer.bat
```

流程：PyInstaller 打 onedir → 复制 ffmpeg → Inno Setup 生成安装包。
产物：`dist\转写助手_Setup_2.0.exe`
